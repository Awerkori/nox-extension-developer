# Contributing

For the Portuguese version, see [CONTRIBUTING.md](CONTRIBUTING.md).

1. Read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and [SECURITY.md](SECURITY.md).
2. For bugs, improvements, compatibility, or documentation, open an issue using the appropriate template. Do not publish vulnerabilities, secrets, or personal data in public issues.
3. Describe the problem and proposed change. For larger changes, discuss the approach before implementing it.
4. Keep changes focused and add or update tests and documentation when needed.
5. Run `python3 -m unittest discover -s tests -v` from the project root.
6. Open a pull request with a summary, motivation, tests, compatibility, and risks. Remove secrets and personal data from examples and logs.

For security issues, follow [SECURITY.md](SECURITY.md), not a public issue.
