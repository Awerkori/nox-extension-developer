# Segurança / Security

## Português

Não abra issues públicas para vulnerabilidades nem publique segredos, dados pessoais ou detalhes exploráveis.

Se o reporte privado de vulnerabilidades estiver habilitado no GitHub, acesse a aba **Security**, escolha **Report a vulnerability** e envie uma descrição, impacto e passos de reprodução sanitizados. Não envie credenciais.

Se essa opção não estiver disponível, procure um canal privado de segurança explicitamente publicado pelos mantenedores. Se não houver um, não divulgue os detalhes publicamente; aguarde a publicação de um canal apropriado. Nenhum prazo de resposta ou versão suportada é garantido nesta política.

## English

Do not open public issues for vulnerabilities or publish secrets, personal data, or exploitable details.

If GitHub private vulnerability reporting is enabled, open the **Security** tab, select **Report a vulnerability**, and provide a description, impact, and sanitized reproduction steps. Do not send credentials.

If that option is unavailable, look for a private security channel explicitly published by the maintainers. If none exists, do not disclose details publicly; wait for an appropriate channel to be published. This policy guarantees no response timeline or supported version.
